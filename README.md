# 影片刮削器 (Video Scraper)

![Flutter](https://img.shields.io/badge/Framework-Flutter-02569B?logo=flutter)
![Dart](https://img.shields.io/badge/Language-Dart-0175C2?logo=dart)
![Version](https://img.shields.io/badge/Version-1.2.1-green)
![Build](https://img.shields.io/badge/Build-GitHub%20Actions-2088FF?logo=github-actions)

**影片刮削器** 是一款基于 **Flutter** 开发的高效 Android 移动端视频刮削与整理工具。能够智能识别本地视频文件的番号，从多个数据源抓取详细的元数据与高清封面，自动生成标准 Emby/Jellyfin/Kodi 通用的 NFO 信息文件，并支持多语言中文字幕下载与视频文件自动分类整理。

## ✨ 核心功能

1. **🔍 智能番号识别**
   - 自动解析文件名（如 `[xxx] ssis00123 1080p.mp4` -> `SSIS-123`）。
   - 过滤常见分辨率与格式干扰词（如 `FHD`, `WEB`, `BLURAY` 等）。

2. **🌐 多源聚合与智能合并**
   - 支持多源并发刮削，自动去重与并集合并（标题、演职人员、系列、类别、发行日期、片长等）。
   - 可针对单个数据源设置自定义镜像站网址。

3. **🖼️ 封面与海报处理**
   - 自动获取高清原图封面（Fanart）。
   - **智能裁剪海报**：自动识别横版封面并裁切出右侧主体作为竖版海报（Poster）。

4. **📁 自动化整理归档**
   - 支持按 **番号**、**番号+标题** 或 **原文件名** 自动建立独立文件夹。
   - 刮削成功后自动将视频文件及关联同名文件（字幕、旧 NFO、海报等）整理归类。

5. **💬 字幕下载（实验性）**
   - 接入字幕站搜索功能，支持独立模式及刮削同步模式。
   - 优先匹配并下载简体中文/繁体中文字幕（`.srt` 格式）。

6. **🛠️ 实用辅助工具**
   - 支持跳过已有 NFO 的视频文件，避免重复刮削。
   - 内置 HTTP 代理配置（支持自定义 Clash/V2Ray 等本地代理地址）。
   - 提供浅色、深色及跟随系统的外观主题设置。

## 📡 支持数据源

| 数据源 | 提取信息类型 | 备注 |
| :--- | :--- | :--- |
| **JavBus** | 完整元数据 + 原图封面 | 支持自定义镜像站 URL |
| **JavDB** | 完整元数据 + 原图封面 | 支持自定义镜像站 URL |
| **DMM** | 高清官方封面 | 根据番号智能拼接官方图床地址 |
| **SubtitleCat** | 中文字幕 (`.srt`) | 支持独立下载与过滤 |

## 📂 整理后的文件目录示范

开启“刮削并整理”后，生成的目录与文件结构如下（以 Emby / Jellyfin / Kodi 规范命名）：

```text
/你的视频目录/
└── SSIS-123/
    ├── SSIS-123.mp4           # 原始视频文件
    ├── SSIS-123.nfo           # 标准影片信息元数据
    ├── SSIS-123-poster.jpg    # 竖版海报（自动裁切）
    ├── SSIS-123-fanart.jpg    # 横版全景背景图
    └── SSIS-123.zh-CN.srt     # 自动下载的匹配字幕
```

## 🛠️ 环境要求与本地构建

### 开发环境
- **Flutter SDK**: `>=3.3.0 <4.0.0`
- **Dart SDK**: `>=3.3.0`
- **Android Studio** 或 **VS Code**

### 本地编译步骤

1. **克隆仓库**
   ```bash
   git clone <你的项目仓库地址>
   cd avguaxiao-main
   ```

2. **安装依赖**
   ```bash
   flutter pub get
   ```

3. **运行或构建 APK**
   ```bash
   # 本地连接设备运行
   flutter run

   # 编译 Release APK
   flutter build apk --release
   ```
   *生成的安装包路径：`build/app/outputs/flutter-apk/app-release.apk`*

## 📖 使用说明

1. **授权存储权限**：首次打开软件需授予 Android **“所有文件访问权限”**（Manage External Storage），以便读取视频和写入 NFO/图片。
2. **设置网络代理（可选）**：如果直连无法访问刮削源，可在右上角 **“设置”** 中配置 `HTTP 代理`（例如：`127.0.0.1:7890`）。
3. **选择文件夹**：
   - 点击 **“选择文件夹并开始刮削”** 执行完整刮削与文件整理流程。
   - 点击 **“只下载字幕”** 仅检索匹配字幕而不变动视频和 NFO 文件。

## ⚠️ 常见问题

- **部分来源提示被拦截（Cloudflare）**：
  由于部分源站启用了抗 DDoS 保护，建议在设置中开启网络代理，或者更换可用的镜像站网址。
- **扫描不到文件**：
  请确保已授予存储权限，且文件后缀名属于常见的视频格式（如 `.mp4`, `.mkv`, `.avi`, `.wmv` 等）。
