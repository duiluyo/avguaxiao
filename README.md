**影片刮削器** 是一款基于 **Flutter** 开发的高效 **Android 手机 / Windows 电脑** 双平台视频刮削与整理工具。能够智能识别本地视频文件（或 NAS / 电脑共享文件夹里的视频）的番号，从多个数据源抓取详细的元数据、高清封面与剧照，自动生成标准 Emby/Jellyfin/Kodi 通用的 NFO 信息文件，并支持标题翻译、多语言中文字幕下载与视频文件自动分类整理。

## ✨ 核心功能

1. **🔍 智能番号识别**
   - 自动解析文件名（如 `[xxx] ssis00123 1080p.mp4` -> `SSIS-123`）。
   - 过滤常见分辨率与格式干扰词（如 `FHD`, `WEB`, `BLURAY` 等），自动去掉 `xxx.com@` 这类网址前缀。
   - 支持 **FC2**（`FC2-PPV-1234567`）和 **日期型番号**（一本道、加勒比等，如 `010123_001`）。
   - 识别文件名后缀：`-C` 自动加「中文字幕」标签，`-U` 加「无码」标签，`-UC` 两个都加。
   - `-CD1`、`-CD2` 等分卷会整理进同一个文件夹，同一个番号在一次刮削中只查询一次。

2. **🌐 多源聚合与智能合并**
   - 支持多源并发刮削，自动去重与并集合并（标题、演职人员、系列、类别、发行日期、片长等）。
   - 可针对单个数据源设置自定义镜像站网址。

3. **🖼️ 封面、海报与剧照**
   - 自动获取高清原图封面（Fanart）。
   - **智能裁剪海报**：自动识别横版封面并裁切出右侧主体作为竖版海报（Poster）。
   - **剧照下载**：保存到 `extrafanart/` 文件夹（`fanart1.jpg`、`fanart2.jpg` …），可选最多 5 / 10 / 20 张或全部。

4. **🈶 标题与类别翻译**
   - 使用谷歌翻译，失败时自动切换到 MyMemory 备用；可选简体中文 / 繁体中文 / English。
   - 译名写入 NFO 的 `title`，日文原标题保留在 `originaltitle`；文件夹名选「番号+标题」时使用译名。

5. **📁 自动化整理归档**
   - **自定义文件夹命名模板**：可用 `{番号}` `{标题}` `{原标题}` `{演员}` `{年份}` `{日期}` `{厂商}` `{系列}` `{导演}` `{原文件名}` 自由组合，内置常用预设，设置里实时显示示例结果。
   - **按演员分类**：模板里用 `/` 表示多层文件夹，例如 `{演员}/{番号} {标题}`；演员超过 3 位归入「多人作品」，没有演员信息归入「未知演员」。
   - 可选择整理在「视频所在文件夹」，或统一整理到「所选根文件夹」（按演员分类时建议选后者）。
   - 刮削成功后自动将视频文件及关联同名文件（字幕、旧 NFO、海报等）整理归类。
   - **撤销上次整理**：每次批处理都会记录操作，可一键把文件移回原位，并删除当次生成的 NFO / 封面 / 剧照 / 字幕（保留最近 10 次记录）。

6. **🗂️ 网络共享（SMB）**
   - 直接选择 NAS 或电脑共享出来的文件夹进行刮削与整理，无需另做 PC 版。
   - 内置共享文件夹浏览器，支持逐级进入、选择目录；视频在服务器上直接改名移动，不经过手机传输。
   - 刮削、整理、撤销、试运行、手动输入番号、字幕下载均支持网络共享。
   - 自动跳过群晖的 `@eaDir`、`#recycle` 等系统目录。

7. **💬 字幕下载（实验性）**
   - 接入字幕站搜索功能，支持独立模式及刮削同步模式。
   - 优先匹配并下载简体中文/繁体中文字幕（`.srt` 格式），已有字幕的视频自动跳过。

8. **🛠️ 实用辅助工具**
   - **试运行预览**：只查询资料并显示将移动到哪里、将生成哪些文件，不改动任何文件。
   - **手动处理失败项**：批处理结束后，未识别或没查到的文件可点击后手动输入番号重试。
   - **连接诊断**：主界面右上角的 📶 按钮（或设置里的“测试连接”）一键检查代理、JavBus、JavDB、DMM 图床、翻译、字幕站和网络共享，显示 ✓ / ✗、原因和耗时，可复制结果，方便排查问题。
   - **屏幕常亮**：批量处理时保持屏幕常亮，避免息屏后被系统中断。
   - 支持跳过已有 NFO 的视频文件，避免重复刮削。
   - 内置 HTTP 代理配置（支持自定义 Clash/V2Ray 等本地代理地址）。
   - 提供浅色、夜间及跟随系统的外观主题设置。
   - 日志可长按选择，也可一键复制，标题栏与日志首行都会显示版本号，方便反馈问题。

## 📡 支持数据源

| 数据源 | 提取信息类型 | 备注 |
| :--- | :--- | :--- |
| **JavBus** | 完整元数据 + 原图封面 + 剧照 | 支持自定义镜像站 URL |
| **JavDB** | 完整元数据 + 原图封面 + 剧照 | 支持自定义镜像站 URL，可能被 Cloudflare 拦截 |
| **DMM** | 高清官方封面 | 根据番号智能拼接官方图床地址 |
| **SubtitleCat** | 中文字幕 (`.srt`) | 支持独立下载与过滤，多为机器翻译 |
| **谷歌翻译 / MyMemory** | 标题与类别翻译 | 谷歌翻译在部分地区需要代理 |

## 📂 整理后的文件目录示范

开启“刮削并整理”后，生成的目录与文件结构如下（以 Emby / Jellyfin / Kodi 规范命名）：

```text
/你的视频目录/
└── SSIS-123/
    ├── SSIS-123.mp4           # 原始视频文件
    ├── SSIS-123.nfo           # 标准影片信息元数据
    ├── SSIS-123-poster.jpg    # 竖版海报（自动裁切）
    ├── SSIS-123-fanart.jpg    # 横版全景背景图
    ├── SSIS-123.zh-CN.srt     # 自动下载的匹配字幕
    └── extrafanart/           # 剧照（可选）
        ├── fanart1.jpg
        ├── fanart2.jpg
        └── ...
```

> 视频没有整理进独立文件夹时，剧照会存到 `视频名-extrafanart/`，避免和同目录其他影片混在一起。

**按演员分类**（模板 `{演员}/{番号} {标题}`）的效果：

```text
/所选根文件夹/
├── 演员A/
│   ├── SSIS-123 影片标题/
│   │   ├── SSIS-123.mp4
│   │   └── SSIS-123.nfo ...
│   └── SSIS-456 影片标题/
├── 演员B/
│   └── ABP-789 影片标题/
└── 多人作品/
    └── XXX-001 影片标题/
```

## 💻 Windows 电脑版

同一份代码同时支持 Windows 电脑版，功能与手机版一致：番号识别、多源合并、封面与剧照、标题翻译、字幕下载、整理到文件夹、试运行预览、撤销整理、手动处理失败项。

**获取方式**：推送代码后，在 GitHub 的 **Actions** 页面打开 `Build Windows` 的运行记录，在底部 **Artifacts** 下载 `video-scraper-windows`，解压后双击 `video_scraper.exe` 即可使用，不需要安装。

**和手机版的区别**：
- 不需要授予存储权限，直接选择文件夹即可。
- 没有“本机存储 / 网络共享”切换和 SMB 设置。要刮削 NAS 或其他电脑共享的视频，请先在 Windows 里把共享文件夹**映射成网络驱动器**（如 `Z:`），再像普通文件夹一样选择它。
- 没有“保持屏幕常亮”选项。
- 若使用 Clash 等软件的“系统代理”模式，请在设置里把代理地址（如 `127.0.0.1:7890`）填到 `HTTP 代理` 中，软件不会自动读取系统代理。

## ☁️ 使用 GitHub Actions 云端打包

仓库中不需要提交 `android` 文件夹，云端打包时会自动生成并补全。需要的文件如下：

```text
仓库根目录/
├── pubspec.yaml
├── lib/main.dart
├── ci/debug.keystore                  # 固定签名文件（见下，仅安卓需要）
└── .github/workflows/
    ├── build-apk.yml                  # 打包安卓 APK
    └── build-windows.yml              # 打包 Windows 电脑版
```

推送代码（或在 Actions 页面手动点击 Run workflow）即可打包，完成后在运行记录底部的 **Artifacts** 中下载：安卓版为 `app-release-apk`，电脑版为 `video-scraper-windows`。

打包脚本会自动完成：
- 补全安卓工程，并添加联网与存储权限；
- 把桌面图标上的应用名改为「影片刮削器」；
- 把 `compileSdk` 提高到 37（`permission_handler` 需要）；
- 注入安卓原生代码以支持“屏幕常亮”；
- 使用 `ci/debug.keystore` 固定签名。

**固定签名**：每次云端打包默认会生成新的临时签名，新版 APK 无法覆盖安装旧版。把 `debug.keystore` 放到仓库的 `ci/` 目录后，所有版本使用同一个签名，之后可直接覆盖安装、保留设置。第一次切换到固定签名时，需要先卸载旧版。该签名文件的密码是公开的默认值，建议把仓库设为私有。

## 📖 使用说明

1. **授权存储权限**：首次打开软件需授予 Android **“所有文件访问权限”**（Manage External Storage），以便读取视频和写入 NFO/图片。
2. **设置网络代理（可选）**：如果直连无法访问刮削源或谷歌翻译，可在右上角 **“设置”** 中配置 `HTTP 代理`（例如：`127.0.0.1:7890`）。
3. **选择来源**：主界面顶部选择 **“本机存储”** 或 **“网络共享”**。
   - 选择“网络共享”前，先在设置里填写服务器地址、用户名和密码；点击选择文件夹后会弹出共享文件夹浏览器，选好文件夹即可。
4. **先选影片，再选操作**：
   - **① 选择影片文件夹**：点击顶部的文件夹卡片，选好后会自动扫描并显示找到的视频数量；点右侧的刷新按钮可重新扫描，点卡片本身可更换文件夹。
   - **② 选择要执行的操作**（选一次文件夹，可以连续执行多种操作，不用重新选择）：
     - **开始刮削**：执行完整刮削与文件整理流程。
     - **试运行预览**：先查看将要发生的操作，不会改动任何文件。
     - **只下载字幕**：仅检索匹配字幕，不变动视频和 NFO 文件。
5. **处理失败的文件**：批处理结束后出现 **“手动处理失败的 N 个”** 按钮，点击文件、输入番号后重试。
6. **整理错了怎么办**：点击右上角 **↩ 撤销上次整理**，文件会移回原位，当次生成的 NFO、封面、剧照、字幕以及新建的空文件夹会被清理。
7. **设置文件夹命名**：在设置的“整理”里选择预设或自己写模板，下方会显示示例结果；想按演员分类，选 `演员/番号` 并把整理位置设为“所选根文件夹”。建议先用“试运行预览”看效果。
8. **连不上时先测试**：点击右上角 📶 **测试连接**，看哪一项是 ✗，按提示处理（例如配置代理），也可以复制结果发给开发者。

## ⚠️ 常见问题

- **部分来源提示被拦截（Cloudflare）**：
  由于部分源站启用了抗 DDoS 保护，建议在设置中开启网络代理，或者更换可用的镜像站网址。
- **扫描不到文件**：
  请确保已授予存储权限，且文件后缀名属于常见的视频格式（如 `.mp4`, `.mkv`, `.avi`, `.wmv` 等）。
- **开着 VPN 时无法连接局域网共享**：
  VPN 默认会让局域网流量也走 VPN，导致连不上 NAS。可以在 VPN 软件里开启“绕过局域网”，或让 `192.168.0.0/16` 直连；这个问题目前暂未在软件里处理。
- **网络共享连不上**：
  使用的 SMB 库只支持 SMB1 / SMB2.0 / SMB2.1，不支持 SMB3。新版 Windows 11 默认强制 SMB 签名、群晖关闭了 SMB2 或强制加密时，都可能连不上；请把错误日志发给开发者排查。
- **用户名和密码安全吗**：
  网络共享的用户名和密码以明文保存在 `刮削器/config.json` 中，请注意保管手机文件。
- **翻译显示“翻译：✗”**：
  谷歌翻译在部分地区无法直连，请在设置中配置 HTTP 代理；翻译失败不影响其他功能。
- **剧照显示“剧照：无”**：
  说明当前数据源没有解析到剧照地址（网站结构可能已变化），不影响封面和 NFO。
- **Windows 提示“Windows 已保护你的电脑”**：
  程序没有购买代码签名证书，第一次运行时点击“更多信息”→“仍要运行”即可。
- **电脑版弹出缺少 DLL 的提示**：
  请安装微软的 VC++ 2015-2022 运行库（x64）后再运行。
- **新版 APK 无法覆盖安装**：
  请按上文放入 `ci/debug.keystore` 固定签名；第一次切换时需要先卸载旧版。
